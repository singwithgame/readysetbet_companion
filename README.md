# Ready Set Bet Companion (Fan-made Desktop App)

This is a **fan-made** desktop application for the "Ready Set Bet" companion web app. It bundles the original WebGL components into a standalone executable that can run on Windows and macOS without installation.

## How to Play

You can download the ready-to-play portable versions directly from the **[Releases](../../releases)** tab! 
- **Windows**: Download the `.exe` file and simply double-click to run. No installation required.
- **Mac**: Download the `.dmg` file, open it, and run the app.
